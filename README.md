# RDCore.Demo.Battleship
<sup>_Ce document est disponible en [français](./README.fr.md)_</sup>

![VIVAT CUCUMIS](./assets/vivat-cucumis-stonecore.png)

RD-VBA Battleship is a naval battle game written in VBA by the author of Rubberduck to show object-oriented VBA: interfaces and `Implements`, factory methods, events between classes, and custom errors. It was legacy Rubberduck's showcase.

This repository holds the game's port to the [RDCore](https://github.com/rubberduck-vba/RDCore) platform, which opens, runs and debugs VBA without Office hosting it.

## Project status

RD-VBA Battleship is in **pre-alpha** development. The game's workspace is not in the repository yet.
