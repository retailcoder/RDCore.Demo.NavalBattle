# RDCore.Demo.Battleship
<sup>_This document is available in [English](./README.md)_</sup>

![VIVAT CUCUMIS](./assets/vivat-cucumis-stonecore.png)

RD-VBA Battleship est un jeu de bataille navale écrit en VBA par l'auteur de Rubberduck pour montrer la programmation orientée objet en VBA : les interfaces et `Implements`, les méthodes de fabrique, les événements entre classes et les erreurs personnalisées. C'était la vitrine de Rubberduck legacy.

Ce référentiel contient le portage du jeu vers la plateforme [RDCore](https://github.com/rubberduck-vba/RDCore), qui ouvre, exécute et débogue du VBA sans qu'Office l'héberge.

## État du projet

RD-VBA Battleship est en développement **pré-alpha**. L'espace de travail du jeu n'est pas encore dans le référentiel.
